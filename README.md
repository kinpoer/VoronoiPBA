## About Project

This project provides MATLAB code for the three-dimensional topological impedance model (3D TpIM) and inverse design workflow of Voronoi plate-lattice acoustic metamaterials. The code builds random Voronoi plate-cavity networks, assembles the TpIM acoustic model, performs manufacturable decoding of perforation parameters, and runs staged optimization strategies for sound absorption design.

## Code Structure

- `TpIMFunctions.m`: reusable geometry, acoustic modelling, optimization, and visualization utilities.
- `runHybridDecoupledOptimization.m`: runs the four-stage spatial-frequency cascade optimization workflow for one random Voronoi TpIM absorber and exports the corresponding results.
- `runM1M6AblationStudy.m`: compares the six optimization variants M1-M6 under a matched TpIM evaluation budget for the ablation study.
- `runM1M6ScalingStudy.m`: compares M1 and M6 for different Voronoi array sizes and summarizes the scaling behaviour.
- `HybridDecoupledOptimizationResults/`, `M1M6AblationResults/`, and `M1M6ScalingResults/`: output folders generated by the scripts.

## Requirements

The code requires MATLAB R2021b or later. The main workflows use Optimization Toolbox, Global Optimization Toolbox, Statistics and Machine Learning Toolbox, Fuzzy Logic Toolbox, and Image Processing Toolbox. Parallel Computing Toolbox is optional and can be used to accelerate genetic algorithm runs when `config.ga.useParallel` is set to `true`.

## Getting Started

Keep all `.m` files in the same folder. Open MATLAB, set the current folder to this `code` directory, or add this folder to the MATLAB search path:

```matlab
addpath(pwd)
```

Then run one of the following scripts according to the required workflow:

```matlab
runHybridDecoupledOptimization
runM1M6AblationStudy
runM1M6ScalingStudy
```

The user-adjustable settings are collected near the beginning of each script under the `User configuration` section. The scripts automatically create their output folders if they do not already exist.

## Note

The optimization examples can be computationally expensive because they rely on repeated TpIM evaluations and genetic algorithm searches. For quick checks, reduce the population size, generation count, or number of independent runs before launching the full study.
